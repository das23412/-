## 一、项目概览

**墨阅**是一款基于 Flutter 的中文小说阅读器，安卓优先（代码兼容 iOS，未打包）。

- **代码仓库**：https://github.com/das23412/- （仓库名就是一个 `-`，是当初建仓时起的，能用，可在 Settings 里改名）
- **发布方式**：GitHub Actions 云端打包 → 自动发布 GitHub Release → 用户在应用内“检查更新”升级
- **产品定位**：本地为主（扫描/导入本机书籍）+ 可选联网能力（链接导入直链下载、Legado 兼容书源引擎——书城/书源三页为 v1.7.0~v1.8.x 新增）
- **核心原则**（改动前必读）：
  1. 不上传任何用户数据，不做内容分发（书源由用户自行导入，不内置任何站点/书单）
  2. 权限最小化：INTERNET、所有文件访问（扫描）、REQUEST_INSTALL_PACKAGES（应用内更新）
  3. 签名必须永远一致（**v1.6.0 起已轮换为私密正式密钥**，见“发版流程”），否则用户无法覆盖安装

## 二、功能清单（用户视角，每项“长什么样”）

### 1. 书架（首页）
- 顶部一条常驻说明：「免费用，如果是购买的话，请立即退款。」
- 三列封面网格（按格式着色的渐变封面：TXT 青 / EPUB 靛 / MOBI 橙 / FB2 紫 / HTML 灰蓝）
- 每本书显示：书名、未读角标（红）、置顶角标（图钉）、最近阅读时间（如“3天前”，未读过显示添加时间）、进度百分比或“已读完”、底部细进度条
- 搜索（AppBar 放大镜）、排序（最近阅读/添加时间/书名）、标签筛选条（ChoiceChip 横滑）
- 长按进入批量模式：多选删除/置顶/全选；点击卡片打开书；右上角 ⚙ 进通用设置
- 右下角「添加书籍」→ 底部抽屉 6 项：手机选文件导入 / 从链接导入 / 全盘扫描 / 管理扫描文件夹 / 清理失效书籍 / 关于与隐私说明
- 权限受限时顶部橙色横幅「未授予所有文件访问」+ 一键去授权
- 扫描有提示条（可点 ⓘ 看扫描报告：存储区数/进入目录数/跳过数/无法读取数）

### 2. 找书/导入
- **全盘扫描**：枚举 /storage 下所有卷（内置+SD卡+U盘），递归找 5 种格式；精确跳过规则（Android/data、隐藏目录等，不会误伤用户自建的同名文件夹如 `1122/data`）
- **候选清单**：扫描结果不直接入库，弹出可勾选清单（文件名/格式/大小），全选/反选，确认才入库；未勾选的可“记住并以后不再提示”（扫描文件夹页可重置忽略列表）；清单里注明微信/QQ 私有目录系统级不可扫
- **手动导入**：系统文件选择器多选
- **其他 App 导入**：QQ浏览器等“用墨阅打开”→ 原生层拷贝到私有缓存 → 自动入书架并打开（不需要任何权限）
- **从链接导入**：粘贴文件直链 → 探测文件名/大小 → 确认框（含流量提醒）→ 进度条下载 → 入书架。只收 5 种格式，500MB 上限，浏览器 UA，http 明文可用；错误均为中文友好提示

### 3. 阅读器
- 点击分区：左 1/3 上一页、右 1/3 下一页、中间呼出菜单
- **四种翻页模式**：仿真（卷页，折缝投影+背面跟随背景色，源码内置自 turn_page_transition MIT）、覆盖（新页滑入盖住旧页+左缘落影）、平移、上下滚动
- **窗口式跨章**：三种翻页模式的翻页器都装载“上一章+当前章+下一章”的页面，章节边界继续滑动无缝进入相邻章（对齐番茄/起点）
- 菜单（两行按钮布局，不会溢出）：上一章/目录/书签列表/下一章；加删书签/设置；进度滑块拖动时实时浮出「第N章 标题（百分比）」；顶栏显示书名+当前章+日夜间快捷切换
- 书签列表：章节名+原文预览+时间，点击跳转、长按删除
- 设置面板：字号(12-32)/行距(1.2-2.6)/首行缩进/翻页模式/五套背景色卡+自定义图片/夜间深色背景开关/导入 .ttf 字体/应用主题（浅色/深色/跟随系统）
- 进度记忆到字符级：换字号后重开书仍准确回到原位置；每本书独立

### 4. 通用设置页
- 「允许联网下载」总开关（默认关；关闭时应用零联网行为）
- 版本与更新：显示当前版本，「检查更新」→ 查 GitHub Releases → 有新版显示版本/大小/说明 → 下载（进度条）→ 立即安装（FileProvider 拉起系统安装器；首次需允许“安装未知应用”）

### 5. 书城 / 书源（v1.7.0~v1.8.x 新增）
- 底部导航栏三页：**书架 / 书城 / 书源**（shell_page.dart）
- 书源页：导入/管理/校验 Legado 兼容书源（lib/source/ 引擎：规则解析、HTTP、搜索与正文抓取隔离线程化，防 ReDoS）
- 书城页：聚合已启用书源的搜索结果，在线加入书架阅读
- ⚠ 原则不变：应用不内置任何书源，站点规则全部由用户自行导入

### 6. 分享链路（设计定位）
- 用户自行上传书到任意能出直链的网盘 → 把直链发给朋友 → 朋友墨阅粘贴导入；分享者删除/改名文件即收回分享
- 墨阅本身不存储、不分发、不内置任何站点（法律安全边界，勿改）

## 四、发版流程（每次改代码后，顺序执行，缺一不可）

0. **修改前备份（强制）**：建 `backup/<日期>` 分支推上去 + 本地源码快照（见发布检查清单第 0 条）
1. **版本号三处同步**：`pubspec.yaml` 的 `version`（+1）、`lib/core/app_info.dart` 的 version/build（⚠ v1.8.4 时 app_info 曾落后于 pubspec，发版前必须核对一致）、提交信息标题
2. `flutter analyze`（零告警）+ `flutter test`（全过，用例数以当前仓库为准）
3. 提交 → `git push`（本机到 GitHub 经常被墙，用后台循环重试，通常几分钟内会通）
4. `git tag vX.Y.Z && git push origin vX.Y.Z` → CI 自动构建并**发布 Release**（应用内更新的数据源）
5. **签名验证**：下载 Release APK，`apksigner verify --print-certs`，指纹必须与正式密钥一致
   （v1.6.0 起为 PKCS12 正式密钥，基准指纹以最近一次验证记录为准；v1.4.x 时代的
   `cf2e97ba...` 调试指纹已作废）。CI 无 Secrets 时会**故意失败**，不产出随机签名包
6. 告知用户可用“设置→检查更新”升级；验证 Release 直链返回 206：`https://github.com/das23412/-/releases/download/vX.Y.Z/app-release.apk`
7. 若版本涉及签名变更，Release 公告必须写明“需卸载重装一次”

## 五、踩坑记录（血泪教训，接手前必读）

1. **签名不一致（v1.4.2 发现→v1.6.0 轮换根治）**：曾以为“复制 keystore 到 ~/.android”就够，但 AGP 9 在 CI 上并不读那个路径 → 每个版本随机签名 → 用户覆盖安装报冲突；钉死仓库内置 debug 密钥后仍未解决“公开仓库任何人可伪造同签名更新”的问题，最终 v1.6.0 轮换为**私密 PKCS12 正式密钥**（Secrets 注入 + 本机 D:\glmchunchu\moyue-release-key\ 双备份）。**密钥文件是最高级别资产，丢失后所有用户永远无法覆盖安装。**
2. **手势竞技场吞点击（v1.4.3）**：TurnPageView 在 `useOnTap:false` 时若仍给 GestureDetector 传非 null 的 onTapUp，识别器照常注册且子组件优先 → 外层“呼出菜单”永远收不到点击 → 仿真模式“只能翻页”。**正解：关闭的交互传 null。** 改翻页器手势时必须真机验证“点中间能呼出菜单”。
3. **外观不刷新（v1.4.4）**：仿真翻页页面列表“仅页数变化时重建”的性能优化，导致换背景/图片不生效。**正解：把外观状态（背景索引/图路径/颜色）纳入 TurnPageView 的重建钥匙，且钥匙变化时连锁重建控制器**（旧控制器已释放，不重建会崩）。
4. **页面必须不透明**：翻页页面若背景透明，覆盖/仿真时新旧两页文字会叠在一起。页面自带 `_pageDecoration()`（色卡或自定义图）。
5. **翻页必须全屏**：页面铺满整屏、文字边距画在页面内部（`_pagePad`），否则翻页效果只在“文字卡片”里动，观感全错。
6. **file_picker 必须锁 10.x**：11.x 安卓实现有编译问题（FilePickerPlugin 找不到符号），且 API 从 `.platform.` 静态调用改成了实例风格，升级需整体适配。
7. **TextPainter.lineMetrics 在新版 Flutter 已移除**：分页引擎用的是 `getLineBoundary` 逐行推进方案，升级 Flutter 若分页错乱先查这里。
8. **网络环境**：本机直连 GitHub 时好时坏（代理 127.0.0.1:65532 不通）；git push 用循环重试总会成功；GitHub API 匿名 60 次/小时易限流，轮询构建状态优先用“Release 直链探测 206”而非 API。**用户浏览器装了自动改写 GitHub 链接的加速代理插件（如 gh.api.99988866.xyz，证书已坏），发给用户的下载链接必须提醒“用系统浏览器、地址栏确认是 github.com”**。
9. **会话中断恢复**：长对话经历过多次上下文压缩，会发现“文件已部分改好但未提交”甚至**本地与远程严重分叉**（本例：本地停在 v1.4.4，远程已到 v1.8.4）。动工前必须 `git fetch` + `git status` + 对比 `git log origin/main`，确认自己是最新状态再动手；落后时先 `git rebase origin/main`。
10. **大改动必留可回退点**：v1.8.x 开发中发生过误删构建配置/平台文件的事故（靠 `git 原样恢复` 救回），这也是发布检查清单把“修改前备份”设为第 0 条的原因。
11. **版本号双源不同步**：app_info.dart 与 pubspec.yaml 曾脱节（1.8.1 vs 1.8.4）——应用内“检查更新”用的是 app_info，脱节会导致版本对比错误。发版清单第 1 条的三处同步必须逐项打勾。

## 六、已知限制（产品决策，非 bug）

- 微信/QQ 接收的文件扫不到：系统禁止读 Android/data，已在前端各处说明，需用户先移到公共目录
- EPUB 图片不渲染（用户决定暂缓，架构留位：需把章节从纯文本升级为“文字段+图片块”三处改造）
- PDF/DOC/PPT 不支持（用户明确取消）
- HUFF/CDIC 压缩的 MOBI、Big5 编码 TXT 不支持（有友好报错提示转格式）
- 重复导入同一本书会生成两条记录（体验优化候选：按“文件名+大小”去重提示）
- iOS 有工程无打包（需要 macOS+开发者账号，用户暂不需要）

## 七、质量与验收基线

- `flutter analyze`：0 问题；`flutter test`：全部通过（用例数随版本增长，改代码后必须保持全绿）
- 真机验收清单（每次发版后跑一遍）：扫描→候选勾选→导入；仿真模式点中间呼出菜单；设置里切换四种翻页方式且**停留原位置**；换背景色卡/自定义图立即生效；章节末尾滑动进下一章；拖进度条显示章节提示；书签加/列/删/跳；链接导入一个真实直链；书源导入→书城搜索→在线阅读；应用内检查更新闭环
